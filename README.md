# Учёт партнёров и услуг

Настольное приложение для работы с партнёрами компании: карточки партнёров, история оказанных услуг и расчёт стоимости. Учебный проект, 2025.

## Что умеет

- список партнёров;
- добавление и редактирование партнёра: наименование, тип, руководитель, email, телефон, адрес;
- история услуг выбранного партнёра;
- расчёт стоимости услуги и количества материала для неё.

## Что лежит в репозитории

- Demo: исходный код приложения;
- ScriptBD.sql: скрипт создания базы данных;
- ER.pdf: ER-диаграмма базы;
- алгоритм.vsdx: блок-схема алгоритма расчёта.

## Технологии

C#, Windows Forms, .NET Framework 4.8, Microsoft SQL Server.

## Запуск

Создать базу скриптом ScriptBD.sql, поменять строку подключения в Demo/App.config на свой сервер и открыть Demo.sln в Visual Studio.
